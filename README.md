LiveSchematics

Веб-приложение для совместного проектирования схем и диаграмм в реальном времени. Позволяет пользователям создавать комнаты, добавлять различные фигуры, редактировать их и работать над проектом совместно.

🚀 Основные возможности


Совместная работа в реальном времени: Создавайте комнаты по уникальному ID и работайте над схемой вместе с коллегами. Все изменения синхронизируются мгновенно.
Drag & Drop интерфейс: Интуитивно понятная панель инструментов. Просто перетащите нужную фигуру на холст.
Разнообразие фигур:

Базовые: Прямоугольник, Круг, Ромб.

Специализированные: Актер (UML), База данных (Цилиндр), Группа (Контейнер).

UML Класс: Умный блок, в который можно "вкладывать" текстовые блоки для создания атрибутов и методов.

Гибкие настройки: Изменяйте цвет фона, границ, текста и размер шрифта через панель инспектора.

Продвинутые связи: Создавайте прямые и ступенчатые связи, добавляйте стрелки, ромбы (агрегация/композиция) и меняйте их стиль.

Комнатная система: Присоединяйтесь к существующим проектам по коду или создавайте новые.


🛠️ Технологии


Frontend: React, React Flow, React Router, Socket.io Client.

Backend: Node.js, Express, Socket.io.

Database: MongoDB (Mongoose).


🎮 Как пользоваться


Главная страница: При входе вы увидите форму. Выберите "Создать", введите имя и название схемы. Система сгенерирует уникальный ID комнаты.

Вход в комнату: Если у вас уже есть ID комнаты, выберите "Подключиться" и введите свой ник и ID.

Работа с холстом:

Добавление фигур: Перетащите иконку из левой панели на холст.

Редактирование: Дважды кликните по фигуре, чтобы изменить текст. Используйте правую панель (Инспектор) для изменения цветов и стилей.

Связи: Потяните за кружочек на границе фигуры к другой фигуре.
UML Классы: Перетащите "Текст" внутрь класса — он автоматически станет строкой в секции атрибутов или методов.

Панель Инспектора:
Здесь находятся настройки выбранного элемента.
Можно свернуть панель для удобства.
В шапке отображается ID комнаты и имя создателя.


📁 Структура проекта


Проект разделен на две основные части:

/client - React приложение.

/src/components - React компоненты (Toolbar, Inspector, Nodes).

/src/hooks - Кастомные хуки для управления логикой (useDiagram).

/src/pages - Страницы приложения (Home, DiagramPage).

/server - Node.js приложение.

index.js - Точка входа, настройка Socket.io и API.


🔮 Планы по развитию


Сохранение истории изменений (Undo/Redo).

Экспорт схемы в PNG/SVG.

Чат внутри комнаты.

Блокировка объектов при редактировании одним пользователем.
